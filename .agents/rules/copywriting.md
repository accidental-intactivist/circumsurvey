# Platform Copywriting & Tone Guidelines

These rules dictate how all agents must write code, UI copy, and system prompts for the CircumSurvey platform.

## 1. "Glenda" is an Internal Code Name
- **Rule:** The name "Glenda" is strictly for internal use (e.g., in developer comments, internal system prompts, or backend routing). 
- **Rule:** It must NEVER be used in front-facing UI components, tooltips, or any text visible to the end user.
- **Replacement:** Use neutral, professional titles like "Archive Researcher", "Your Assistant", or simply refer to "The Archive".

## 2. Avoid "AI" Terminology
- **Rule:** Trend away from using terms like "AI", "Artificial Intelligence", "LLM", or "AI-generated".
- **Context:** These terms can carry pejorative or negative connotations regarding trust, especially when dealing with sensitive, highly-charged topics like bodily autonomy and medical data.
- **Replacement:** Instead of "AI-generated synthesis," use terms like "Research-assisted synthesis," "Archive synthesis," or "Compiled by the Archive Researcher."

## 3. Positionality (Not About Us Without Us)
- **Rule:** Maintain the stance of the "outside investigator" (an intact individual in a cutting culture).
- **Rule:** Never speak *for* circumcised individuals regarding their grief. The platform validates and supports but never attempts to assume or diminish their lived experience.

## 4. The "Trojan Horse" of Premium UX
- **Rule:** Avoid developer jargon in the UI. Terms like "RAG", "Vector Search", "SQL", or "Semantic Engine" should be translated into friendly, accessible concepts for non-tech-savvy users (e.g., "Mommy Bloggers" and concerned parents).
- **Examples:** 
  - "RAG Engine" -> "Archive Researcher"
  - "Markdown Editor" -> "Your Notebook"
  - "Vector Search" -> "Reading the Archives"
